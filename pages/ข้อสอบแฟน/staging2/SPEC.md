# SPEC — ข้อสอบแฟน ชุดใหม่ (ประเมิน / แนวคิด)

แต่ละ "ไฟล์ต้นฉบับ = 1 บท (chapter)" → 1 JSON

## Schema JSON (ต้อง json.load ผ่าน)
{
  "id": "a1",                 // ตามที่กำหนดในงาน
  "set": "ประเมิน",           // "ประเมิน" หรือ "แนวคิด"
  "no": "1",                  // ลำดับตามที่กำหนด
  "icon": "🦴",               // emoji เหมาะกับเนื้อหา
  "title": "ชื่อบทจริงจากเนื้อหา",
  "desc": "คำอธิบายสั้น 1 ประโยค",
  "source": "ชื่อไฟล์ pdf",
  "summary": "markdown ภาษาไทย — ## หัวข้อย่อย, bullet สั้น, ปิดท้าย ### เคล็ดลับจำ",
  "questions": [
    {"q":"...","choices":["ก","ข","ค","ง"],"answer":0,"explain":"อ้างเนื้อหาจริง"}
  ]
}
- questions 12-15 ข้อ, 4 ตัวเลือก, answer index 0-3 กระจาย, explain อ้างเนื้อหาจริง ห้ามมั่ว
- summary ครอบคลุมทุกหัวข้อหลัก, เน้นตัวเลข/คำนิยาม/ขั้นตอน

## กติกา
- เขียนไฟล์ JSON ให้เสร็จ "ทีละไฟล์ทันที" หลังอ่านไฟล์นั้นจบ (อย่าสะสม raw text หลายไฟล์แล้วค่อยเขียน — กัน context ล้น)
- ไฟล์นามสกุล .json เท่านั้น, ensure UTF-8, ภาษาไทย
- ห้ามแก้ไฟล์อื่นนอกจาก JSON ที่ได้รับมอบหมาย
- ก่อนจบ: ตรวจ json.load ผ่านทุกไฟล์ แล้ว print path + title + จำนวนข้อ
