# SPEC — ข้อสอบนายสิบตำรวจ (สายอำนวยการ)

เว็บมี 6 วิชา แต่ละวิชาแบ่งเป็น 3 หัวข้อย่อย — "1 ไฟล์ JSON = 1 หัวข้อย่อย"

## Schema JSON (ต้อง json.load ผ่าน)
{
  "id": "g1",
  "set": "gen",                 // วิชา: gen|th|en|tech|law|soc
  "no": 1,                      // ลำดับหัวข้อในวิชา (1,2,3)
  "icon": "🧮",
  "title": "ชื่อหัวข้อย่อย",
  "desc": "คำอธิบายสั้น 1 ประโยค",
  "source": "เกร็งจากแนวข้อสอบนายสิบตำรวจ (สายอำนวยการ)",
  "summary": "markdown ภาษาไทย — ## หัวข้อย่อย, bullet สั้น อ่านง่าย, สูตร/ตัวเลข/คำนิยาม, ปิดท้าย ### เคล็ดลับจำ",
  "questions": [
    {"q":"...","choices":["ก","ข","ค","ง"],"answer":0,"explain":"วิธีคิด/เหตุผล"}
  ]
}
- questions 12-15 ข้อ, 4 ตัวเลือก, answer index 0-3 กระจาย, explain อธิบายวิธีคิด สั้นชัด
- summary ต้องเป็นเนื้อหาที่อ่านสอบได้จริง ครอบคลุมหัวข้อ มีตัวอย่าง/สูตร

## รายชื่อไฟล์ (id / set / no / วิชา-หัวข้อ)
- g1 set=gen  no=1 การคิดคำนวณ (เลขพื้นฐาน/ร้อยละ/กำไร–ขาดทุน/ดอกเบี้ย)
- g2 set=gen  no=2 อนุกรมและตรรกะ (อนุกรมเลข/มิติสัมพันธ์/เงื่อนไขสัญลักษณ์)
- g3 set=gen  no=3 การวิเคราะห์เหตุผล (อุปมาอุปไมย/การให้เหตุผล/สรุปความ)
- t1 set=th   no=1 หลักภาษา (การสะกดคำ/คำเป็นคำตาย/ชนิดคำ)
- t2 set=th   no=2 การอ่านจับใจความและตีความ
- t3 set=th   no=3 สำนวน สุภาษิต คำพังเพย
- e1 set=en   no=1 Grammar พื้นฐาน (tense/part of speech/agreement)
- e2 set=en   no=2 Vocabulary & Conversation
- e3 set=en   no=3 Reading Comprehension
- c1 set=tech no=1 คอมพิวเตอร์เบื้องต้น (ฮาร์ดแวร์/ซอฟต์แวร์/ระบบปฏิบัติการ)
- c2 set=tech no=2 อินเทอร์เน็ตและเครือข่าย
- c3 set=tech no=3 ความปลอดภัยไซเบอร์และการใช้เทคโนโลยีอย่างปลอดภัย
- l1 set=law  no=1 กฎหมายอาญาเบื้องต้น
- l2 set=law  no=2 กฎหมายแพ่งและพาณิชย์เบื้องต้น
- l3 set=law  no=3 กฎหมายอื่นที่ประชาชนควรรู้ (จราจร/ยาเสพติด/พรบ.ตำรวจ)
- s1 set=soc  no=1 สังคมและวัฒนธรรมไทย
- s2 set=soc  no=2 หน้าที่พลเมืองและกฎหมายในชีวิตประจำวัน
- s3 set=soc  no=3 จริยธรรมและจรรยาบรรณตำรวจ

## กติกา
- เขียนไฟล์ JSON ให้เสร็จ "ทีละไฟล์ทันที" (อย่าสะสม raw text หลายไฟล์ — กัน context ล้น)
- ไฟล์ .json เท่านั้น, UTF-8, ภาษาไทย
- ห้ามแก้ไฟล์อื่นนอกจาก JSON ที่ได้รับมอบหมาย
- ก่อนจบ: ตรวจ json.load ผ่านทุกไฟล์ แล้ว print path + title + จำนวนข้อต่อไฟล์
